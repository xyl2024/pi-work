# 02: 用户消息头按来源渲染（UI + i18n）

**What to build:** 聊天界面的用户消息头部从写死的「用户头像 + 昵称」改为按消息来源单点分发渲染，模板只有一套：网页端（含缺省/无标记）维持现状的头像 + 昵称；频道来源显示频道图标 + 频道名；定时任务来源显示任务图标 + 任务名；子代理会话来源显示机器人图标 + 父会话标题。每种来源悬停显示完整说明（如「来自频道 XX」「来自定时任务 XX」「来自会话 XX」），文案走 i18n 词典机制，不硬编码单语言文本。本轮只展示、不跳转。历史消息与乐观插入的本地消息自然落进缺省规则。用测试夹具造出来的带来源消息即可演示全部视觉效果。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 消息头部渲染完全由共享层的来源映射纯函数驱动，组件内无来源判定逻辑
- [ ] 无 origin 的消息渲染与改动前逐像素一致（头像、昵称、回退昵称「You」、i18n）
- [ ] 四种来源在测试夹具下渲染正确的图标 + 名称 + 悬停文案
- [ ] 悬停文案新增的词典键覆盖现有语言，不硬编码单语言文本
- [ ] 长名称（频道名/任务名/会话标题）有合理的截断，不撑破消息头部布局
- [ ] TypeScript 检查、ESLint 通过
