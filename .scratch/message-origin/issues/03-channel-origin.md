# 03: 频道入站消息标记来源

**What to build:** 微信频道的入站消息交给会话时，由频道发送方在 prompt 命令上填好频道来源（频道 id + provider + 频道名快照）。端到端效果：从微信频道发来的消息在会话里显示频道图标 + 频道名（悬停「来自频道 XX」），网页端手动输入同会话仍显示用户头像 + 昵称；prompt 文本与现状完全一致、无任何包装或前缀；频道改名后历史消息仍显示发送时刻的名称快照；历史回放与实时流（SSE）显示一致。

**Blocked by:** 01, 02

**Status:** ready-for-agent

- [ ] 频道冷启动与复用会话两条路径的入站消息都带频道来源
- [ ] `/new` 频道重置命令不受影响，仍按现有机制处理
- [ ] prompt 文本与改动前逐字节一致（不加前缀/后缀/标记）
- [ ] 同一会话混合「频道消息 + 网页手动输入」时，两种消息的来源标识各自正确
- [ ] 历史 API 与实时 SSE 两种读取路径显示一致
- [ ] TypeScript 检查、ESLint、相关单元测试通过
