# 04: 定时任务触发消息标记来源

**What to build:** 定时任务到点触发、把任务 prompt 送进会话时，由定时任务发送方填好任务来源（任务 id + 任务名快照）。端到端效果：任务触发的会话里，用户消息显示任务图标 + 任务名（悬停「来自定时任务 XX」）；任务被删除后，历史消息仍显示删除前的名称快照，不丢信息；任务 prompt 原样进入会话，无包装；历史回放与实时流显示一致。

**Blocked by:** 01, 02

**Status:** ready-for-agent

- [ ] 任务触发的用户消息带定时任务来源
- [ ] 任务 prompt 与改动前逐字节一致
- [ ] 删除任务后，历史消息仍显示名称快照（不因实体消失而显示空白或报错）
- [ ] 任务改名后，历史消息仍显示发送时刻的名称快照
- [ ] 历史 API 与实时 SSE 两种读取路径显示一致
- [ ] TypeScript 检查、ESLint、相关单元测试通过
