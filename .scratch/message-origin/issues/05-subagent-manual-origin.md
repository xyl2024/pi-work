# 05: 子代理会话手动输入标记来源

**What to build:** 用户在子代理会话的输入框手动补输入时，由该输入路径填好子代理会话来源（父会话 id + 父会话标题快照 + 子会话 id）。端到端效果：补输入的消息显示机器人图标 + 父会话标题（悬停「来自会话 XX」），父会话标题取发送时刻快照；补输入的既有规则完全不受影响——一次一个未完成任务（忙碌拒绝）、全局并发队列、request 去重、父会话 stop-all 窗口、配置冻结。历史回放与实时流显示一致。

**Blocked by:** 01, 02

**Status:** resolved

- [ ] 补输入的用户消息带子代理会话来源（父会话 id + 标题快照 + 子会话 id）
- [ ] 父会话标题是发送时刻快照：之后重命名父会话不影响已有消息的显示
- [ ] 非子代理会话的手动输入不受影响（网页端照常显示头像 + 昵称）
- [ ] 补输入的忙碌拒绝、并发队列、request 去重、stop-all 窗口等既有行为不变
- [ ] 历史 API 与实时 SSE 两种读取路径显示一致
- [ ] TypeScript 检查、ESLint、相关单元测试通过
