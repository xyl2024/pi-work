# 07: 重启后对账与安全继续

Category: enhancement
Status: ready-for-agent

**What to build:** 服务重启后，用户和父 agent 能识别中断任务、读取保留历史，并显式继续子会话；不会把遗留 running 记录当作仍在执行或自动重放原输入。

**Blocked by:** 05: 在已有子会话中继续委派.

**Status:** ready-for-agent

- [ ] 启动时对未确认仍执行的遗留非终态任务标记中断，包括排队、创建、执行和停止中记录；对账可重复运行。
- [ ] 不自动重放任务、不自动唤醒父回合，保留错误/原因、部分输出及已有任务历史。
- [ ] get/list 和 UI 正确显示中断，不持续按遗留 running 轮询；中断会话可显式 continue。
- [ ] 冷启动恢复创建时受限配置和子代理身份，不套用已更改档案、不扩大工具或权限；档案被删除也不破坏已有完整快照。
- [ ] 旧数据快照缺失时仅使用可靠可恢复的受限配置，关键配置不足明确失败，不能默认扩大能力。
- [ ] 重启后相同 spawn/continue 请求标识仍去重，不重复执行有副作用的输入；继续新请求正常生成独立任务。
- [ ] 通过重新打开临时持久化存储模拟重启，验证迁移幂等、任务对账、历史保留、配置恢复和去重，不读取真实用户数据。
