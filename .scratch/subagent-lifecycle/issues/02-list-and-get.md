# 02: 查询子代理会话、任务详情与结果

Category: enhancement
Status: ready-for-agent

**What to build:** 父 agent 通过 list/get 找回直属子代理会话，查看任务状态、活动、错误和结果；用户看到的子会话列表与工具查询反映同一受管理执行状态。

**Blocked by:** 01: 改名为 subagent，打通创建与独立等待.

**Status:** ready-for-agent

- [ ] list 返回当前父会话直属子会话摘要和最新任务，支持状态筛选与分页，不因多轮历史把同一会话重复列为多项。
- [ ] get 可用 task_id 查询某任务，也可用 session_id 查询最新任务摘要及分页任务历史。
- [ ] 详情包含时间、状态、错误、近期工具活动、结果及可用的异常部分输出；结果与对话记录支持有界分页读取。
- [ ] 任何截断均明确标记并提供继续读取方式；列表默认不返回全量 prompt、对话或结果。
- [ ] 所有标识查询校验直属归属，已知其他父会话的子标识也不能读取，非法/缺失标识明确失败。
- [ ] 现有 UI 子会话列表和活动详情与工具查询使用一致的任务状态来源，不能永远轮询僵死 running 记录。
- [ ] 外部接口测试覆盖分页、筛选、截断、部分输出、任务/会话定位和越权访问；多任务历史验收在 continue 可用后完成，不为此增加对 05 的依赖。
