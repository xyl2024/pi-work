# 03: 重新等待已有任务

Category: enhancement
Status: ready-for-agent

**What to build:** 父 agent 在一次创建等待结束后，通过 task_id 重新等待同一子任务，无需重新发送输入或启动新任务。

**Blocked by:** 01: 改名为 subagent，打通创建与独立等待.

**Status:** ready-for-agent

- [ ] wait 精确定位当前父会话直属子代理的某次任务，不默认跟随该会话后来的任务。
- [ ] 默认有界等待与 spawn 保持一致，支持零等待和缩短等待；超时返回真实当前状态及等待超时标记。
- [ ] 已完成或其他终态任务立即返回对应结果、错误和可用的部分输出，不创建或重放回合。
- [ ] 多个等待者或重复 wait 不启动新任务，等待取消或到期不取消子任务、不释放执行槽位。
- [ ] 通过工具 seam 与可控时钟验证先超时后完成、再次等待、多等待者、终态立即返回及归属校验。
