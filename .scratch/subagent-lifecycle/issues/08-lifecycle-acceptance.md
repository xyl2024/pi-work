# 08: 完整生命周期验收与入口一致性

Category: enhancement
Status: ready-for-agent

**What to build:** 用户与父 agent 能完整完成创建、等待到期、查询、再次等待、继续、总停止和重启后跟进；工具、通用输入及 UI 入口对同一任务给出一致行为。

**Blocked by:** 03: 重新等待已有任务; 06: 用户手动跟进也进入任务管理; 07: 重启后对账与安全继续.

**Status:** ready-for-agent

- [ ] 通过主要工具 seam 完成 spawn 等待到期后后台继续、list/get 找回、wait 拿结果、continue 新回合、精确 cancel 和父总停止的连续场景。
- [ ] 跨用户手动输入与 agent 委派验证同一会话无重叠回合，停止期间不漏并发新建任务，后续任务不被旧 cancel 影响。
- [ ] 通过重启场景验证中断记录、显式继续、历史结果及配置快照恢复，不自动重试。
- [ ] 检查所有工具、输入、停止和详情入口的直属归属校验、禁止递归、子代理身份保持及重命名后工具选择；新旧卡片均可展示，旧名不能调用。
- [ ] 确认 UI 对排队、执行、停止中、终态、中断与截断表达一致，父回合结束后可正常发送并独立停止后台任务，所有新增文案国际化。
- [ ] 各前置 ticket 自带行为测试，本票只补跨流程缺口，不重复内部实现断言，不把测试全部延后到此票。
- [ ] 执行匹配改动的类型/lint 与隔离行为测试；不擅自启动 UI 测试、不运行覆盖共享构建目录的日常生产构建，报告已验证及未执行的人工验收。
