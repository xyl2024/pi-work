# 01: 改名为 subagent，打通创建与独立等待

Category: enhancement
Status: ready-for-agent

**What to build:** 父 agent 使用 subagent 的 spawn 动作创建子代理任务，默认等待 15 分钟，也可立即返回。等待结束后任务仍由后台管理，界面持续展示真实状态。旧工具选择迁移为新名称，旧名称不再接受调用，历史记录仍可阅读。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 新工具以 action 区分参数，spawn 保留档案名称、描述与输入；未知档案和非法参数返回明确错误。
- [ ] spawn 默认等待 900000 毫秒，支持更短等待与零等待；返回稳定 task_id、可用时的 session_id、当前状态及等待是否到期。
- [ ] 等待超时不取消任务、不释放执行槽位、不拆除后台任务管理；父回合正常结束、连接断开、关闭标签页或父实例空闲回收不丢失子任务。
- [ ] 持久化为后续同会话多任务保留独立任务记录和创建时配置快照，旧任务数据与父子关联可读，迁移幂等。
- [ ] 全局最多 4 个子任务执行，超额 FIFO 排队；排队时间计入等待时限但不耗任务运行时限。
- [ ] 复用既有回合执行 seam，agent_settled 才结束回合；运行时限到期须确认底层回合停止，不能仅销毁 wrapper 并虚报终态。
- [ ] 创建返回与实时卡片/活动状态一致，排队时尚无子会话标识也可跟踪；保留已有结果分类语义和异常部分输出。
- [ ] 工具注册、提示词、选择配置和新卡片统一使用 subagent；旧选择加载时迁移，不注册旧调用入口，不重写旧消息且保持旧卡片可读。
- [ ] 当前父会话归属由上下文确定，子代理不能因工具改名或配置迁移获得递归委派能力。
- [ ] 通过工具外部接口及可控回合 adapter 验证默认时限、零等待、后台完成、FIFO 和真实终止；使用隔离数据及可控时钟，完成相关类型或 lint 检查。
