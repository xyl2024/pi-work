# 06: 用户手动跟进也进入任务管理

Category: enhancement
Status: ready-for-agent

**What to build:** 用户打开子代理会话查看、停止或继续工作时，操作和父 agent 委派进入同一任务管理，避免未被记录、无法总停止的手动回合。

**Blocked by:** 05: 在已有子会话中继续委派.

**Status:** ready-for-agent

- [ ] 打开子会话可查看历史和当前任务，手动输入生成独立任务记录并可被父 agent 查询，能够区分手动提交的输入。
- [ ] 已知子会话的通用用户输入入口必须经过任务管理，不能绕过 busy、并发调度、请求去重或父会话总停止。
- [ ] 手动继续不把子代理转换为普通会话，不自动提升权限或替换创建时配置；停止功能作用于正确任务。
- [ ] 子代理不继承父完全访问模式，权限确认遵循既有快速拒绝规则；无人可回答的提问立即明确失败，不无限挂起。
- [ ] 已有界面显式调整子会话权限模式的规则仍适用，不提供 agent 自动提权入口。
- [ ] 用户输入与父 agent continue 同时提交时最多启动一个未结束任务；手动任务也可被父总停止取消。
- [ ] 入口契约及交互闸门测试覆盖身份保持、手动输入被跟踪、并发 busy 和提问快速失败；UI 文案国际化，人工 UI 验收遵守项目启动限制。
