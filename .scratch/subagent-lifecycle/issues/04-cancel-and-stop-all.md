# 04: 单任务取消与父会话总停止

Category: enhancement
Status: ready-for-agent

**What to build:** 父 agent 可取消指定任务；用户点击父会话停止时停止父回合和所有未结束子任务。即使父回合已结束，用户仍有独立的停止全部子任务入口。

**Blocked by:** 01: 改名为 subagent，打通创建与独立等待.

**Status:** ready-for-agent

- [ ] cancel 仅按 task_id 作用于直属子任务，重复取消安全，不能误停该子会话后来启动的任务。
- [ ] 排队任务取消后不再启动；执行中任务先进入停止中，确认回合停止后才进入取消终态并释放槽位和会话。
- [ ] 完成结果已落地时，迟到取消不能覆盖终态和结果；并发完成/取消/超时不导致重复释放或假终态。
- [ ] 用户父会话停止级联取消所有未结束子任务（含队列），父会话删除也取消；普通等待到期和父回合正常结束不触发总停止。
- [ ] 总停止开始后临时拒绝新的 spawn；后续 continue 及手动继续也须复用此规则。停止完成后可显式重新委派。
- [ ] 父回合运行时原停止入口执行总停止；父回合已结束且仍有未结束子任务时提供独立停止全部入口，不占用发送按钮，同类命令入口一致。
- [ ] 界面区分停止中与已取消，不承诺回滚已发生操作或终止任意脱离管理的进程，用户文案遵循国际化机制。
- [ ] 测试覆盖后台任务总停止、排队取消、停止与创建竞争、停止中槽位占用、迟到取消、父删除和再次委派；使用真实入口契约验证父停止能到达统一任务管理。
