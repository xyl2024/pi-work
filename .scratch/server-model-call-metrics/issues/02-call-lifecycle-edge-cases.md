# 02: 异常、重试和并发调用保持统计可信

**What to build:** 失败、取消、内部重试、用量缺失与并发模型调用都能在审计 API 中查到符合父 spec 的记录；统计过程不会干扰调用本身。沿用 01 的采集、存储、查询链路和测试边界。

Blocked by: 01 — 主聊天调用的三个指标可查询

Status: done

- [x] 覆盖首输出前失败、首输出后失败、部分用量后取消、没有最终助手消息而抛异常：每次已发起的逻辑调用保留一条记录，终态明确区分失败、取消与成功，两个 TPS 在失败和取消时均为 null。
- [x] 首输出已经到达时，后续失败或取消仍保留 TTFT、实际已知用量及时间事实；未观测到的值不伪造为零。进程内终态处理后清理订阅和临时状态。
- [x] 区分服务商最终报告的实际零用量和 SDK 初始化的占位零。没有可靠 usage、负值或非有限用量时 TPS 为 null；实际零用量在正常完成且分母有效时允许得到零 TPS。
- [x] 检查 SDK 的 usage 初始化与真实回报行为；无法可靠判定是否报告时如实按未知处理并说明适配能力边界，不能凭默认字段存在就推定已报告。
- [x] 生成窗口缺失或不大于零、全程耗时不大于零及无效时间事实不产生伪造 TPS。API 不出现 NaN、Infinity 或以空字符串表达未知，TPS 不为显示目的截断精度。
- [x] 一次逻辑调用内部请求失败、退避后重试成功只产生一条性能记录，TTFT 和全程耗时包含内部等待。操作终止后上层再次发起生成则产生新记录，不改变 SDK 重试策略及 HTTP 审计粒度。
- [x] 两个调用同毫秒开始、交错输出并相反顺序完成时，两条记录均保留；模型、来源、用途、usage 与首尾输出时间不串用。
- [x] 重复终止回调、会话事件重放和 SSE 重连不新增记录或重复计费，已结束调用不被其他调用的收尾覆盖。
- [x] 审计写入失败不改变原本成功的模型结果或原始业务错误；不新增正文日志、密钥日志或额外模型请求。
- [x] 使用 01 的受控输出到真实审计 API 验收边界，覆盖以上状态、重试时序、usage 与并发样本；验证回复内容、输出顺序、取消信号与错误传播保持原有行为。
- [x] 测试使用临时存储，不访问真实用户数据或付费模型，不触发服务启动；完成匹配范围的 TypeScript、ESLint 和测试。无需等待其他业务入口切片。

## Comments

- 实现加固：
  - `finish` 归一化无效间隔（负数/非有限 → `null`），不再可能写入伪造时间事实；
    `terminalStatus` 在 `signal.aborted` 时也归为 `cancelled`。
  - 终态后在 `finally` 中执行 `cleanup`：删除对 stream `push` 的补丁（恢复原型方法）
    并释放计时状态；写入失败时同样清理。
  - `readReportedOutputTokens` 的注释补充了 pi-ai 1.2.0 各 adapter 的 usage 初始化与
    `reasoning` 回报差异，并注明 bedrock/mistral 的全零真实报用量会被保守视为未知。
- 新增验收（`tests/unit/model-call-metrics.test.ts`，13 个生命周期用例）：
  首输出前失败、首输出后失败、部分用量后取消、无最终消息的 result reject、
  同步 setup throw、写入失败保留原始错误、负值/NaN/Infinity 用量、零/负时间事实、
  内部重试只记一条且 TTFT 含退避、结束后再次生成记两条、同毫秒并发交错且逆序完成、
  流内容与顺序保持、取消信号保持、终态后移除 push 补丁且重放不重复、API 仅有限数值或 null。
- 验证：`tsc --noEmit`、ESLint（改动文件）、单文件 vitest（27 passed）、
  `pnpm test`（98 files / 1257 tests passed）。未做真实服务商 smoke test。
- 代码审查后补充修复：
  - `token-audit-store` 的逐调用查询不再对 metric 行 `COALESCE` 计费行的
    `output_tokens` / `duration_ms`：否则“未报告用量”（NULL）会被计费占位 0 覆盖，
    在 API 层伪造零 TPS / 零耗时；旧记录仍走 legacy 分支保留原值。新增 join 场景回归测试。
  - 未知 `done`/`error` reason 不再默认成功；`error` 事件在 signal 已 abort 时归为取消，
    `done` 事件不被 abort 信号反转。
  - 指标初始化/观测阶段自身抛错时降级为“不观测”，不影响业务调用；部分补丁会回滚。
  - 测试隔离日志（`PI_WORK_LOG_FILE=off`），不再写真实 `~/.pi-work/logs`；
    测试文件头注释说明 `PI_WORK_TEST_SKIP_INSTANCE=1` 的使用方式。
  - 并发样本改为同 session / 同模型 / 同毫秒起始、交错输出逆序完成，并断言 callId 不碰撞、
    usage 与首尾时间不串用；取消信号断言 wrapper 原样透传。
