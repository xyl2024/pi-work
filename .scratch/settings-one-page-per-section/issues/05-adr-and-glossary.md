# 05: 记录决定：ADR + 术语更新

**What to build:** 把「设置分区就是页」这个决定写进 `docs/adr/`，并修掉 `CONTEXT.md` 里因为这次改造而失真的两条定义。

ADR 需要说清三件事：为什么设置分区从「滚动定位的单元」变成「一次只显示一个的单元」；被删掉的锚点体系（滚动锚点属性 + IntersectionObserver + 平滑滚动）为什么该删；以及取舍 —— 分组永不可点击、切页不记滚动位置、记住上次停留的分区、脏页用同一个确认形态拦住。不写固定像素宽度这类会过期的细节。

术语更新：`CONTEXT.md` 的「设置分区」定义为「侧栏导航与内容区一次只显示一个的单元」，「设置分组」保留「视觉小标题、不可点击、不参与导航」。**不新增「设置页」这个同义词** —— 术语仍用「设置分区」，避免同义词污染。同时记录这次新增的概念：「未保存改动」现在同时决定关窗确认和切页确认（原本只决定关窗）。
