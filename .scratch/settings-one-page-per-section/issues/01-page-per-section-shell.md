# 01: 分页骨架：一次只渲染一个设置分区

**What to build:** 打开设置弹窗，左侧是分组小标题 + 10 个设置分区，点任意一个分区，右侧只出现那一页的内容，并从页首开始。分组小标题不可点击。当前页在导航里有明确选中态，也带 `aria-current="page"` 供读屏软件识别。每页正文顶部有该页的页标题（取自设置注册表），弹窗页头仍只有「Settings」和关闭按钮、且页标题不 sticky。瞬时光标切页、无过渡动画、不记忆每页滚动位置。

页壳取代原来只挂锚点的空壳包装：它负责页标题、可选说明、统一内容内边距。整层「用 DOM 属性当信息架构」的机制（滚动锚点属性、IntersectionObserver 滚动高亮、平滑滚到锚点）随本次改造删除。页渲染从 `switch` 改成以设置分区 id 为键的映射，漏实现一页会在类型检查阶段失败。

弹窗宽度从 880 提到 960，并加 `min(960px, calc(100vw - 32px))` 兜底，高度仍为 70vh。保存语义、关窗确认文案、子代理编辑弹窗、Developer 分组的次级语气均不变。

**Blocked by:** None (can start immediately)
