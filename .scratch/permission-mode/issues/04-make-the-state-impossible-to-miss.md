# 04: 让这个状态躲不掉

**What to build:** 把「这个会话不会再弹窗」变成躲不掉的信息。激活完全访问时：输入区容器的描边转红（这是「下一次不会询问」唯一常驻的提醒）；工具条上的模式按钮转红；悬停时 Tooltip 写清边界——它放过了什么、没放过什么（除自保护外一切照跑，自保护仍然是硬拦截）；会话标签页与会话侧栏行各挂一枚红色盾牌徽章。

徽章是 03 的配套义务：持久化 + 无人记得 = 一个被焊死的洞，所以必须有一个不依赖用户主动去看的常驻指示。

## Comments

- 输入区描边转红（`FULL_ACCESS_BORDER_COLOR`，比思维等级那档红色更实，两者不会看混），工具条按钮转红并带
  浅红底；两处红色常量收在 `components/ui/permission-mode-colors.ts` 一个模块里——同一个信号用三个近似红
  会读成三种状态。
- Tooltip 两档各有文案，完全访问那条写明「除自保护外不再询问」；语言落在 `i18n-dict/permissions.ts`
  （与确认弹窗同一份），不散到输入区词典。
- 徽章 `components/ui/PermissionModeBadge.tsx`：完全访问时红色盾牌，会话标签页与会话侧栏行共用同一个组件，
  确认模式下什么都不渲染（否则安全状态会变成噪音）。它读 `hooks/permissionModeStore.ts` 的覆盖值、
  回落到会话列表报的 `permissionMode`，所以冷启动（会话没被打开过）也能看见盾牌。
- 跨会话索引的写入时机有个坑：controller 挂载时、REST 快照还没折进运行时状态之前，状态里的 `confirm`
  是「还没有信念」而不是事实。若此时就写 store，一个列表里已经写着 full_access 的会话会被闪成无盾。
  所以镜像 effect 用一个 `permissionModeKnownRef`（快照折进之后才置真）挡在写之前；草稿升级成会话时
  直接置真——新会话的 `confirm` 是确定事实，不需要等回填。
- 焦点：切换用的是原生 `<button>`，点击后焦点自然留在触发元素上，键盘用户不会丢焦点（没有额外 JS 抢焦点）。
