# 03: 详情页模型区块与切换 UI

`Category: enhancement`
`Status: resolved`

**What to build:** **图标偏好**的用户入口。**模型配置**面板里 Subscriptions / API Key provider 的详情页新增「模型」区块：列出该 provider 在**模型目录**下的全部模型（含当前未鉴权可见的），每行显示当前生效图标；自动匹配成功的行提供两态切换（匹配图标 ↔ provider 图标），匹配结果与 provider 图标相同、或该模型无匹配时隐藏切换入口；模型超过 8 个默认折叠、点开全铺。切换即时落盘并全端生效：点一下，聊天工具栏、模型选择弹窗、助手消息头、翻译、定时任务里的图标全部跟着变。切换入口只对 API Key / Subscriptions 来源的模型开放；自定义 provider 的模型沿用既有图标挑选字段，不加第二入口。全部文案走 i18n 机制。

**Blocked by:** 01（匹配与可见性规则）、02（偏好读写 API）

- [ ] Subscriptions / API Key provider 详情页展示该 provider 目录下全部模型的列表与当前生效图标
- [ ] 自动匹配成功的模型行提供两态切换，即时写回偏好 store 并立即反映在本行
- [ ] 匹配结果与 provider 图标相同、或无匹配的模型行不显示切换入口（规则来自纯函数，UI 只做薄壳）
- [ ] 超过 8 个模型默认折叠，可展开全部
- [ ] 切换后聊天工具栏、模型选择弹窗、助手消息头、翻译面板与气泡、定时任务表单与详情的图标同步变化
- [ ] 自定义 provider 的模型行不出现切换入口
- [ ] 全部用户可见文案走 i18n 机制，无硬编码单语言文本
- [ ] TypeScript 检查与 ESLint 通过
