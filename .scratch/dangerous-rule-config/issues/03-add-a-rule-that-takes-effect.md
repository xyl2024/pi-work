# 03: 写——新增一条规则，保存即生效

**What to build:** 用户在危险命令页点「新建」，填名字和正则，保存；规则出现在列表里，并且**立刻**在真实会话里生效——跑一条匹配的命令，确认弹窗弹出，弹窗上的规则名与刚建的那条对得上。不需要重启服务，也不需要新建会话。

这一刀要同时立起两块地基：一是共享的规则草稿与校验模块（本轮只含三个阻断项：名字为空、正则为空、正则编译失败），二是独立的写路由（读出磁盘配置、只替换这个配置项、写回；写盘前全量编译，坏正则返回 400 且磁盘不动）。写通路刻意不并入设置接口那套「客户端持整份配置、diff 出变更键」的机制：这一页要的是服务端算出来的生效集，形状对不上。

**Blocked by:** 01（看见——生效集接口 + 危险命令页 + 内置规则只读展示）

**Status:** ready-for-agent

- [ ] 共享草稿/校验模块能由「磁盘上的用户规则 + 当前平台的内置集」算出可编辑草稿、唯一一个阻断项、以及要提交的请求体；纯函数，可直接单测
- [ ] 阻断项至少覆盖：名字为空、正则 trim 后为空（并说明空正则匹配一切）、正则编译失败
- [ ] 新增写路由：读-改-写整份配置，只替换该配置项；写盘前编译全部正则，任一失败即 400，磁盘保持原样
- [ ] 页面能列出用户规则、能新建规则、能保存；保存控件复用已有的三态保存按钮
- [ ] 保存后无需新会话即生效（依据：匹配在每次工具调用时读配置，编译结果按平台 + 规则内容做缓存键）
- [ ] 页面文案全部进设置用的 i18n 字典，中文界面下无英文残留
- [ ] 测试：纯模块覆盖三个阻断项；接口覆盖写入往返（写后读一致，测试结束恢复原状）与坏正则 400
