# 04: 改——编辑、删除、排序

**What to build:** 规则列出来之后要能维护：点一行进编辑器改正则并保存、删掉一条误报的规则、用上移/下移调整顺序。列表顶部有一行说明「顺序只影响同一命令命中时显示和记忆的规则名，不影响是否弹窗」——因为所有规则的动作都是同一个确认，顺序的唯一可观察效果就是这个。

列表行显示名字、正则原文（等宽字体、超长截断）、是否忽略大小写的可读状态。

编辑用独立的弹层而不是行内展开：一条规则要放名字、正则、大小写开关和行内错误，行内编辑会与排序按钮挤在一起。
