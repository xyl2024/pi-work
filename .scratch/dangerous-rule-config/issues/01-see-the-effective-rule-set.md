# 01: 看见——生效集接口 + 危险命令页 + 内置规则只读展示

**What to build:** 用户打开设置弹窗，Agent 分组里多出一页「危险命令」，页面上列出**当前平台真正生效**的那套内置危险命令规则（bash 那套 everywhere，PowerShell 那套只在 Windows），并明确写着「上面的自定义规则清空也不会关掉这些」。这一页读得到的内置集，就是闸门真实在用的那份——不是另一份抄本。

同时，服务端要能回答一个此前回答不了的问题：一条命令命中的是**用户的规则**还是**内置规则**。今天的匹配只回一个规则名，页面要标来源，所以生效集的组装必须保留出处。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 新增的读接口返回当前平台的 `platform`、内置规则集（名字 / 正则 / 是否忽略大小写）、以及用户规则里编译失败的那几条
- [ ] Windows 上内置集含 PowerShell 那套，Linux / macOS 上不含
- [ ] 设置注册表里新增分区，归 Agent 分组，标签文案为「Dangerous commands」/「危险命令」；注册表一致性测试与类型检查通过
- [ ] 页面把内置规则列为只读清单，并显示「清空自定义规则不会关掉这些」的说明
- [ ] 生效集组装能对一次命中给出规则来源（用户 / 内置），并保持「用户规则在前、内置在后、首个命中者胜」的既有语义
- [ ] 生效集里如果存在编译失败的用户规则，接口把它们带出来（供后续页面标红），不在服务端静默丢弃
