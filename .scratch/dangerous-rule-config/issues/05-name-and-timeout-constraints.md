# 05: 守——名字约束与超时字段

**What to build:** 让「配错」在保存前就被挡住，而不是变成一个安静的错误。名字重复、或与内置规则同名，保存被拒并指出冲突对象——因为**规则名就是会话级「总是允许」的备忘键**，重名会让一次放行同时放过两条规则，也会让确认弹窗显示的名字和用户以为的那条对不上。超时改成页面上可编辑的数值；非法值被拒绝，而不是静默回落到默认值（静默回落是手改配置文件时代的妥协，有界面之后就是在替用户猜）。

**Blocked by:** 03（写——新增一条规则，保存即生效）

**Status:** ready-for-agent

- [ ] 名字重复、与内置规则同名时保存被拒，错误文案指出冲突的是哪一条
- [ ] 阻断项的判定顺序固定：名字为空 → 名字重复 → 与内置冲突 → 正则为空 → 正则编译失败 → 超时越界（一次只报一个）
- [ ] 超时可在页面上编辑，越界或非数值被拒绝而不是静默回落默认值
- [ ] 测试：纯模块覆盖冲突名、撞内置名、超时越界三个阻断项及其顺序；接口覆盖冲突名返回 400
- [ ] 「接受灾难性回溯（ReDoS）风险、不做静态分析」这个决定写成代码注释，不留成沉默
