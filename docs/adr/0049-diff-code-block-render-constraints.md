# diff 块渲染取舍为固定常量与固定视觉，不开放配置

0048 定了解析与 token。这条记录渲染层从代码读不出来的约束，防止后续被当作「可以顺手改」推翻。

**决策：没有 `@@` 头的行不显示行号，也不编造行号。** 裸 `+` / `-` 片段（模型手写而非 git 产物）没有真实的行号来源；伪造「看起来合理」的行号会让读者把假数字当成补丁事实。行号列只在 hunk 头给出真实起点后递增。

**决策：diff 块不叠语法高亮。** 行级红绿底色已经承载「这行是什么」的语义；再叠 Prism 的 `inserted`/`deleted` token 着色会出现两种绿叠在一行上，且行内高亮暗示的语义（如字符串、关键字）与 diff 语义无关。行内容按纯文本渲染。

**决策：红绿只来自行分类，行分类只来自解析 token。** 组件不根据内容猜测颜色；换主题只换 token 值，不动组件。

**决策：折叠阈值 40 行、上下文 3 行、截断上限 3000 行是固定常量，不做用户配置。** 这三个数字是排版判断，不是用户偏好：没有用户请求过调整，暴露配置项只增加设置面与测试面。要改时改常量再评估默认值，而不是先建配置。常量集中在 `lib/shared/diff-block.ts` 导出，与其他 diff 纯函数同处一个 seam。

**决策：文件条只显示新路径；旧新路径不同才显示「旧 → 新」。** diff 的消费者关心的是「现在这个文件是什么」。路径相同时旧路径是冗余信息；重命名时旧路径是理解变更的必要信息才出现。删除文件的旧路径仍显示（新路径为空），否则文件条无内容可读。

**决策：横向滚动条沿用全局细滚动条。** diff 块替换 `<pre>` 后在聊天区里仍是「一个代码块」，视觉上不应因为是 diff 就长出另一套滚动条；细滚动条由 globals.css 的全局 `::-webkit-scrollbar` 规则承载（滚动条约束见 ADR-0041），diff 块作为其中一员继承，不新立规格，`.syntax-highlighted-code` 上不再叠加 4px 定制。

**决策：Git 面板与 markdown diff 块共用 token，但不合并组件。** 共用 token 保证两处红绿一致、换主题一处生效；不合并是因为面板视图带有截断提示与工具栏语义，markdown 块带有折叠与回退语义，合并只会得到一个两边都要带开关的胖组件。

## Considered options

- **把折叠阈值等做成设置项。** 无用户诉求，先建配置是提前抽象；弃。
- **无 hunk 头时按起始行 1 递增编造行号。** 数字看似完整但纯属虚构，误导性强于留空；弃。
- **diff 块与 Git 面板合并为一个组件。** 语义集合不相交（折叠/回退 vs 截断提示/工具栏），合并后 props 变成模式开关；弃。
