# 子代理任务独立于工具等待，父会话停止级联取消

子代理工具扩展为 `subagent`，支持创建、列表、详情、等待、继续与取消。子代理会话保存可复用的上下文，每次委派形成独立子代理任务，对应一个回合；任务的生命周期由任务管理拥有，不能随某次工具等待返回而丢失。`spawn` 和 `continue` 默认等待 15 分钟，等待超时仅解除等待，档案运行时限独立约束任务执行。

我们选择让父回合正常结束和会话标签页关闭后子任务继续，以便长任务可查询、再次等待和跟进；同时将用户点击父会话“停止”定义为停止父回合及全部未结束子任务，包含排队任务。停止期间拒绝新委派，正在停止的任务在确认回合结束前继续占用会话和并发槽位，避免总停止漏掉并发创建或旧任务与新任务重叠。父会话删除也取消子任务；进程重启后不自动重放中断任务，避免重复执行副作用。

同一子会话一次只能接受一个未结束任务。继续复用创建时确定的配置及权限身份，用户手动继续也必须经过同一任务管理。第一版只允许父会话控制直属子代理，禁止递归委派，不自动向父会话注入完成消息；这些限制使任务归属、停止范围和结果消费保持明确。

不保留 `spawn_subagent` 调用兼容入口；已有工具选择迁移到新名称，历史工具调用仍可展示。术语见根目录 GLOSSARY.md；具体动作和行为规格记录于 `.scratch/subagent-lifecycle/spec.md`。本决策记录已确认的目标行为，实现尚待整体设计最终确认。
